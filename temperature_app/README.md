# Temperature Statistics

Многомодульное консольное приложение на C.

Файлы:
- main.c — ввод данных и меню;
- temp_api.h — структура и прототипы;
- temp_api.c — реализация функций;
- Makefile — сборка через make.

Сборка:
    make

Очистка:
    make clean

Формат записи:
year month day hour minute temperature

Температура: от -99 до 99.
Количество записей: от 1 до 1000.
