# Итоговое задание — «Статистика температуры»

Консольное приложение на C по требованиям из `Итоговое задание.pdf`.

## Возможности
- чтение CSV с разделителем `;`;
- массив структур `Temperature`;
- среднемесячная, минимальная и максимальная температура;
- среднегодовая, минимальная и максимальная температура;
- `-h`, `-f <filename.csv>`, `-m <номер месяца>`;
- проверка каждой строки и пропуск некорректных строк с выводом номера строки;
- сборка через `make`.

## Сборка
```bash
make
```

## Запуск
```bash
./temperature_app -f input.csv
./temperature_app -f input.csv -m 6
./temperature_app -h
```

Windows/PowerShell:
```powershell
.\temperature_app.exe -f input.csv
.\temperature_app.exe -f input.csv -m 6
```

## Очистка
```bash
make clean
```

## Структура
- `main.c` — аргументы командной строки и управление программой.
- `temp_functions.h` — структуры и прототипы функций.
- `temp_functions.c` — реализация чтения и расчёта статистики.
- `Makefile` — сборка.
- `input.csv` — тестовый корректный файл.
- `bad_input_example.csv` — тест ошибочных строк.

## Табличный вывод

Полный запуск выводит таблицу из 12 месяцев с колонками: месяц, средняя температура, минимум, максимум и количество показаний. Для месяцев без данных показывается «нет данных». Ниже выводится отдельная строка-таблица со статистикой за год. При использовании `-m` выводится таблица только для выбранного месяца.
